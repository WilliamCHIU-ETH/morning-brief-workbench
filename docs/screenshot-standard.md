# 截圖選頁標準（從真人剪輯反推）

## 意圖（2026-08-29，使用者與 agent 對齊後寫入）

**問題**：素材格「哪一句該配哪一頁、框什麼」目前是 `stages/capture-shots.mjs` 裡我們自己猜的
規則，不是來自任何被市場驗證過的標準。第一支端到端成片（`projects/20260826-yadian-test`）
已經出現三類選頁錯誤：同一頁連放兩格、旁白講成交量黃框卻在指數點位、一句點兩檔只開第一檔。
另外「哪些內容根本不適合配籌碼K線截圖」也還沒有判準——這個反面清單跟正面規則同等重要，
它就是 plan 階段「押回主播」的依據。

**做法**：從 IG `cmchipk` 真人剪輯的系列抽樣逐秒反推：每一句旁白配了什麼——主播還是截圖、
截圖是哪一頁、框了什麼、何時捲動或移框。要擴大樣本時回頭向使用者要授權。

**產出（都住在這份檔案）**：正面清單（句型 → 頁面 → 錨點）、反面清單（不配截圖的內容）、
對 `capture-shots.mjs` 的落地清單。

**成功判準**：規則回放到已拆解的 reel 逐素材格預測「配哪一頁」命中 ≥ 8/10；
下一支我們自己的片不再出現「同頁連放」「旁白與框不對題」。

**邊界**：本檔只管「句子 → 頁面 → 錨點」。節奏（素材何時出現）依使用者 2026-08-28 裁定維持
嚴格交替；逐秒證據放 `docs/reference-reels.md`，本檔只放蒸餾出的規則。

## 反面清單：真人也不配截圖、留在主播臉上的內容

1. **宏觀與外部環境**：美債殖利率、油價、地緣政治、制裁、Jackson Hole、資金避險。
2. **產業邏輯與供需故事**：AI 推升先進製程、疫情後首見需求、先進封裝崛起（0824 盤後日報中段 50 秒全主播）。
3. **公司計畫與引述**：董事長說、新廠投產、產能目標 1.6 倍。
4. **已公布財報的解讀**：NVIDIA 營收 962 億美元／年增 106%——0827 大盤小報整段 24 秒留在主播
   （對照：**還沒發生**的財報預告配 NVDA 頁）。App 畫面裡沒有這些數字，硬配就是「旁白與畫面不對題」。
5. **懸念、觀察點、風險與判斷**：「明天看兩件事」「先別急著解讀成翻多」「與其追漲停不如等回檔」。
6. **跨日回顧**：「昨天我們說…」。

一句話版本：**畫面上有的數字才上畫面；故事、判斷、還沒發生的事留在人臉上。**
